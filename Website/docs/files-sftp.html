基础 SFTP 只依赖服务器的 SFTP 子系统。远程编辑、归档和目录同步还需要服务器允许 SSH 命令并提供 python3，两者应分开判断。Basic SFTP depends only on the server's SFTP subsystem. Remote editing, archives, and directory sync also require SSH commands and python3; treat these capability levels separately.

基础 SFTP 文件管理Basic SFTP file management

  • 浏览目录；创建文件和文件夹；重命名、移动及递归删除。Browse directories; create files/folders; rename, move, and recursively delete.
  • 上传和下载，显示字节进度、速度与剩余时间，并支持取消和失败重试。Upload/download with byte progress, speed, ETA, cancel, and retry.
  • 同名目标可覆盖、跳过或自动重命名；支持中文、空格及特殊字符路径。On conflicts, overwrite, skip, or auto-rename; supports Chinese, spaces, and special path characters.
  • 可为每台服务器设置默认进入目录。Configure a default remote directory per server.

移动端后台限制Mobile background limits

进入后台会中断连接与传输；回到前台后需明确重试，当前不承诺文件夹上传、断点续传或恢复部分传输。Backgrounding interrupts connections and transfers. Retry explicitly after returning; folder upload, resume, and partial-transfer recovery are not promised.

远程编辑 · macOSRemote editing · macOS

编辑器支持多标签、行号、搜索、语法高亮及 UTF-8、UTF-16、GB18030。上传前执行版本冲突检查，并采用临时文件与原子替换；乐观检查不是跨进程事务锁。The editor supports tabs, line numbers, search, syntax highlighting, UTF-8, UTF-16, and GB18030. Upload performs version conflict checks and atomic replacement through a temporary file; this optimistic check is not a cross-process transaction lock.

  • 默认最多同时打开 5 个文件，总输入 10 MB。Defaults to 5 open files and 10 MB total input.
  • 超过 200,000 字符的文件不进行语法高亮。Syntax highlighting is disabled above 200,000 characters.
  • 本地草稿按版本保存；退出时先安全落盘，失败可重试或取消退出。Versioned local drafts are saved before shutdown; failed saves can be retried or shutdown cancelled.

用本地应用打开Open with a local app

  1. ServerDash 下载一份私有本地副本，并交给默认应用打开。ServerDash downloads a private local copy and opens it with the default app.
  2. 本地修改不会自动回传；点击“上传修改”后才检查远端版本。Local edits are not uploaded automatically; Upload Changes first checks the remote version.
  3. 确认无冲突后回写。单份本地副本上限 512 MB。Confirm to write back when no conflict exists. Each local copy is limited to 512 MB.

清理是显式操作Cleanup is explicit

移除记录或删除主机不会自动删除磁盘上的本地副本，避免静默数据丢失。Removing a record or deleting a host does not silently remove local copies from disk.

目录同步 · macOSDirectory sync · macOS

默认流程是手动双向扫描、差异预览和逐项确认。删除及双边修改始终作为冲突；符号链接不跟随。The default workflow is manual two-way scanning, difference preview, and per-item confirmation. Deletes and dual-sided changes are always conflicts; symbolic links are not followed.

  • 单次扫描最多 10,000 项，普通文件内容上限 512 MB。Each scan handles up to 10,000 items and regular file content up to 512 MB.
  • 自动模式只在 App 前台观察本地新增/修改并上传；不下载、不删除、不盲目重试。Auto mode only observes local additions/changes while the app is foregrounded and uploads them; it does not download, delete, or blindly retry.
  • 这不是 rsync，也不是后台常驻双向同步。This is not rsync or a resident background two-way sync service.
