安装与快速开始Install & quick start

从正确的发布附件开始，核对校验值并连接第一台 Linux VPS。Choose the right release artifact, verify it, and connect your first Linux VPS.

v1.0.4 · Build 9

macOSiPhone / iPad第一台服务器First server下一模块Next module

ServerDash 需要 macOS 14 或更高版本；移动端 Target 需要 iOS/iPadOS 18 或更高版本。公开 Release 可直接提供 macOS DMG，移动 ZIP 仅用于 Xcode Simulator。ServerDash requires macOS 14 or later. The mobile target requires iOS/iPadOS 18 or later. Public releases provide a macOS DMG, while mobile ZIP files are for Xcode Simulator only.

安装 macOS 版Install on macOS

macOS 14+Apple SiliconIntel
  1. 从官网或 GitHub Release 下载 ServerDash-1.0.4-macOS.dmg。Download ServerDash-1.0.4-macOS.dmg from the website or GitHub Release.
  2. 同时下载 SHA-256 文件，在终端运行校验命令并比对结果。Download the SHA-256 file and compare it with the result of the verification command.
  3. 打开 DMG，将 ServerDash 拖入“应用程序”。Open the DMG and drag ServerDash into Applications.
  4. 首次运行时按住 Control 点击 App 并选择“打开”，或在“系统设置 → 隐私与安全性”中允许运行。On first launch, Control-click the app and choose Open, or allow it in System Settings → Privacy & Security.
shasum -a 256 ServerDash-1.0.4-macOS.dmg
!
为什么需要手动确认？Why is manual confirmation required?

当前 DMG 使用 ad-hoc 签名且未经 Apple 公证。它不是 Developer ID、Mac App Store 或已公证分发。The current DMG is ad-hoc signed and not notarized. It is not a Developer ID, Mac App Store, or notarized distribution.

iPhone 与 iPadiPhone and iPad

使用公开 Simulator ZIPUse the public Simulator ZIP

  1. 在安装 Xcode 26 的 Mac 上下载 iPhone 或 iPad Simulator ZIP。On a Mac with Xcode 26, download the iPhone or iPad Simulator ZIP.
  2. 解压并启动对应的 iOS 18+ Simulator。Extract it and start a matching iOS 18+ Simulator.
  3. 将解压出的 ServerDashMobile.app 拖入模拟器，或用 simctl install 安装。Drag ServerDashMobile.app into Simulator, or install it with simctl install.
×
不能安装到实体设备Not for physical devices

公开 ZIP 声明的是 iPhoneSimulator 平台。仓库不提供 IPA、TestFlight 或 App Store 包；实体设备需在 Xcode 中选择开发团队后自行运行。Public ZIP files target iPhoneSimulator. No IPA, TestFlight, or App Store package is provided. Physical devices require building from Xcode with your own development team.

添加第一台服务器Add your first server

  1. 打开“机器”并选择添加 SSH 服务器。Open Machines and choose to add an SSH server.
  2. 填写名称、主机地址、端口（默认 22）和用户名。Enter a name, host address, port (22 by default), and username.
  3. 选择密码或私钥身份。移动端仅支持密码及导入的 OpenSSH Ed25519/RSA 私钥。Choose password or private-key authentication. Mobile supports passwords and imported OpenSSH Ed25519/RSA keys only.
  4. 保存或测试连接。首次连接会暂停并显示主机指纹，请在确认来源后保存信任。Save or test. The first connection pauses to show the host fingerprint; save trust only after verifying it.
  5. 从机器详情打开监控，或新建终端/SFTP 标签。Open monitoring from machine details, or create a terminal/SFTP tab.
i
配置可以离线保存Profiles can be saved offline

SSH 测试结果与是否保存机器相互独立。监控能力不可用也不必然阻止终端或基础 SFTP。Saving a machine is independent from the SSH test result. Unsupported monitoring does not necessarily block terminal or basic SFTP.
