macOS、iPhone 与 iPad 都是原生界面，但不是功能完全一致的三个外壳。移动端聚焦前台监控、SSH 与 SFTP；桌面端提供专业路线、文件工作流、录制和可选服务。macOS, iPhone, and iPad all use native interfaces, but they are not feature-identical shells. Mobile focuses on foreground monitoring, SSH, and SFTP; desktop adds professional routes, file workflows, recording, and optional services.

下载与分发状态Downloads and distribution

macOS

通用 DMG，包含 arm64 与 x86_64；ad-hoc 签名，未经 Apple 公证，不通过 Mac App Store 分发。Universal arm64/x86_64 DMG; ad-hoc signed, not notarized, and not distributed through the Mac App Store.

iPhone / iPad

公开 ZIP 是 arm64/x86_64 Simulator App。无 IPA、TestFlight 或 App Store 包；实体设备需自行在 Xcode 签名运行。Public ZIP files are arm64/x86_64 Simulator apps. No IPA, TestFlight, or App Store package; physical devices require your own Xcode signing.

移动端前台与后台行为Mobile foreground and background behavior

移动端根页面在 App 前台统一管理监控，因此切换 ServerDash 内部功能页不会停止采集。进入系统后台后连接会中断；回到前台后监控可重新采集，但终端与文件传输必须由用户明确重启。The mobile root owns monitoring while the app is foregrounded, so switching ServerDash pages does not stop collection. System backgrounding interrupts connections; monitoring can collect again on return, while terminals and transfers require explicit restart.

!
不会恢复远程进程或断点续传No remote process or transfer resume

重连会建立新的 Shell，并重新读取配置、凭据与主机信任；不能恢复后台前的远程进程或部分文件传输。Reconnect creates a new shell and reloads configuration, credentials, and host trust. It cannot restore prior remote processes or partial transfers.

RDP 远程桌面：开发中RDP remote desktop: in development

DEV
不属于稳定能力Not a stable capability

macOS 应用包含内嵌 RDP 开发实现，供受控测试。真实 Windows 登录、音频、文件交换、多显示器与长期性能尚未完成互操作验收。The macOS app includes an embedded RDP implementation for controlled testing. Real Windows login, audio, file exchange, multi-display operation, and long-term performance have not completed interoperability validation.

当前代码包含 FreeRDP/WinPR 3.31.0 与 OpenSSL 3.5.8，已实现 NLA/CredSSP、TLS 1.2+、证书指纹确认及显示/键盘/重定向配置。自签或自签发证书链会进入 TOFU 确认；工作组本地账户可从证书公用名补域。这些路径仍属开发中，不能当作已验收登录。实现存在不等于目标 Windows 环境已兼容；iPhone/iPad 不提供 RDP。Current code includes FreeRDP/WinPR 3.31.0 and OpenSSL 3.5.8 with NLA/CredSSP, TLS 1.2+, certificate fingerprint confirmation, and display/keyboard/redirection configuration. Self-signed or self-issued chains reach TOFU confirmation; workgroup local accounts may inherit a single-label certificate common name as the NLA domain. These paths remain in development and are not a validated logon. Implementation does not prove compatibility with a target Windows environment. Mobile has no RDP.

已知限制与验证边界Known limitations and validation boundaries

  • 不是无人值守 7×24 云监控、后台告警或团队共享平台。Not unattended 24×7 cloud monitoring, background alerting, or a team-sharing platform.
  • Mac 与移动端数据库和 Keychain 独立，不自动同步秘密，也不使用 CloudKit。Mac and mobile databases/Keychains are independent; secrets do not sync automatically and CloudKit is not used.
  • Alpine、BusyBox、非 Linux 与异常 Shell 环境不在当前支持范围。Alpine, BusyBox, non-Linux, and unusual shell environments are outside current support.
  • 真实 WebDAV、生产代理/多跳、Remote Forward、硬件密钥、实体串口/VNC 和移动真机辅助功能仍需现场验证。Real WebDAV, production proxies/multi-hop, Remote Forward, hardware keys, physical serial/VNC, and mobile-device accessibility still require field validation.
  • AI 服务可用性、费用与保留政策由用户选择的提供商决定；录制不提供自动可靠脱敏或防篡改审计。AI availability, cost, and retention depend on the chosen provider; recording has no reliable automatic redaction or tamper-proof audit guarantee.
