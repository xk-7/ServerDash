标签、分屏与网格Tabs, splits, and grids

  • SSH 标签没有固定数量上限，但仍受设备内存和服务器连接限制。SSH tabs have no fixed count limit, but device memory and server limits still apply.
  • 每标签最多 16 个独立 SSH 面板，可连接不同主机并整理为最多 4×4 网格。Each tab holds up to 16 independent SSH panes across hosts, arranged in a grid up to 4×4.

连接生命周期Connection lifecycle

会话由工作区控制器持有，切换页面、服务器或功能页不会自动断开。普通“选择机器”会复用该主机最近使用的 SSH 面板；只有“新建标签”或“分屏”创建独立连接。Workspace controllers own sessions, so changing pages, servers, or features does not disconnect them. Normal machine selection reuses the most recent SSH pane; only New Tab or Split creates a separate connection.

!
布局只保存在内存Layouts are in memory only

重启应用不会自动恢复连接或执行命令。移动端进入后台会中断连接；显式重连会创建新 Shell，不恢复远程进程。Restarting does not reconnect or run commands. Mobile backgrounding interrupts connections; explicit reconnect creates a new shell and does not restore remote processes.

搜索、高亮、历史与片段Search, highlighting, history, and snippets

滚屏搜索与高亮Scrollback search and highlighting

Ctrl+F（Mac 也支持 ⌘F）搜索保留的滚屏。内置 15 个高亮预设，支持最多 32 条自定义正则与 12 种颜色；高亮不修改复制内容，复杂正则受执行预算限制。Ctrl+F (also ⌘F on Mac) searches retained scrollback. Fifteen presets, up to 32 custom regex rules, and 12 colors decorate without changing copied text; complex regex execution is bounded.

命令历史Command history

命令栏使用本地历史、Linux 命令库和片段，选择建议只会填入文字。自动捕获直接终端输入需要 OSC 133 Shell 集成，仅支持当前 Bash 4.4+ 或 Zsh 会话，不写远端启动文件。The command bar uses local history, Linux commands, and snippets; selecting a suggestion only fills text. Capturing direct terminal input requires OSC 133 integration for the current Bash 4.4+ or Zsh session and does not modify startup files.

  • 最多保留 2,000 条，可关闭、搜索或清空。Keeps up to 2,000 entries with disable, search, and clear controls.
  • 不采集原始按键和密码回答；前导空格、赋值、控制字符与已识别敏感词会阻止保存。Raw keys and password responses are not captured; leading spaces, assignments, controls, and recognized sensitive terms suppress storage.
  • 过滤无法识别所有秘密，处理其他敏感参数时请关闭历史。Filtering cannot detect every secret; disable history for other sensitive arguments.

提交前先预览固定的已连接 SSH 面板和命令，再向该目标列表发送。后来连接的面板不会被自动加入；本地 Shell、串口与 RDP 不进入 SSH 批执行。Preview a fixed list of connected SSH panes and the command before submission. Later connections are not added automatically; local Shell, serial, and RDP are excluded.
