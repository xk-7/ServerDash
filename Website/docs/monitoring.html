“无需 Agent”表示不用安装常驻守护进程或配套服务。监控仍会通过 SSH 执行 Shell 命令，并可能在 /tmp 创建短期采样或缓存文件。“No agent” means no resident daemon or companion service. Monitoring still runs shell commands over SSH and may create short-lived sampling or cache files under /tmp.

采集的指标Collected metrics

CPU / Load

总体与每核心使用率、温度、Load Average、进程及登录用户。Overall/per-core usage, temperature, load averages, processes, and logged-in users.

内存Memory

内存、缓存、Swap 及使用率。Memory, cache, swap, and utilization.

磁盘与网络Disk & network

文件系统容量、块设备吞吐、IOPS、延迟、接口速率与累计流量。Filesystem capacity, block throughput, IOPS, latency, interface rates, and totals.

GPU / Docker / vnStat

按能力显示 NVIDIA GPU、Docker 只读状态和 vnStat 时间历史。Capability-gated NVIDIA GPU, read-only Docker state, and vnStat time history.

i
不可用能力会明确隐藏或说明Unavailable capabilities are hidden or explained

GPU、Docker 与 vnStat 依赖对应远端命令或服务。vnStat 未安装或尚无历史时不会伪装为零数据；Docker 不是容器管理功能。GPU, Docker, and vnStat depend on remote tools or services. Missing vnStat data is not shown as zero, and Docker support is not container management.

首次采集显示等待状态。失败后保留最后成功数据，同时显示数据年龄和过期提示；自动重试采用封顶退避，手动刷新可跳过等待。The first collection shows an explicit waiting state. Failures preserve the last successful sample while showing age and staleness; retries use capped backoff, while manual refresh bypasses the wait.

本地历史与 Data GapLocal history and Data Gaps

macOS本地存储Local storage
  • 范围：24 小时、7 天、30 天及自定义；按宽度选择原始、1 分钟或 15 分钟分辨率。Ranges: 24 hours, 7 days, 30 days, or custom; resolution selects raw, 1-minute, or 15-minute data based on width.
  • 缺口会断开折线并显示阴影，不使用旧值连接成伪连续趋势。Gaps split chart lines and use shading; stale values are never connected into a false continuous trend.
  • 原因包括超时、不可达、认证失败、指纹变化、Mac 睡眠、本机断网、Collector 停止/不支持和未知失败。Reasons include timeout, unreachable host, authentication failure, host-key change, Mac sleep, local network loss, collector stop/unsupported, and unknown failure.
  • 默认保留原始样本 24 小时、1 分钟聚合 30 天、15 分钟聚合一年；默认配额 512 MiB。Defaults: raw samples for 24 hours, 1-minute aggregates for 30 days, 15-minute aggregates for one year, with a 512 MiB quota.
