机器配置保存地址、端口、用户名和认证引用；密码、私钥正文与口令由 Keychain 保存，不进入 SwiftData，也不放到命令行参数中。Machine profiles store addresses, ports, usernames, and authentication references. Passwords, private-key bodies, and passphrases live in Keychain—not SwiftData or command-line arguments.

组织与查找机器Organize and find machines

三端支持名称、地址、用户名、标签和备注的组合搜索，并可按名称、分组或添加时间排序。分组、标签和监控开关不会改变 SSH 凭据。All platforms search across name, address, username, tags, and notes, with sorting by name, group, or creation time. Groups, tags, and monitoring state do not alter SSH credentials.

macOS

层级分组、网格/Table、多选整理、协议筛选和隐私模式；可同时管理 SSH、VNC、串口及开发中的 RDP 记录。Hierarchical groups, grid/Table views, multiselect, protocol filters, and privacy mode; manages SSH, VNC, serial, and RDP-in-development records.

iPhone / iPad

聚焦可连接的 SSH 主机。桌面连接类型即使存在于共享模型，也不会进入移动端连接或监控页面。Focused on connectable SSH hosts. Desktop-only connection records do not enter mobile connection or monitoring screens.

身份、密码与 SSH 密钥Identities, passwords, and SSH keys

  • 身份可以复用用户名和认证方式；正在被机器引用的身份或密钥不能直接删除。Identities can reuse usernames and authentication methods; referenced identities and keys cannot be deleted directly.
  • macOS 支持密码、外部私钥路径、导入 Keychain 的私钥、加密私钥口令，以及私钥优先/密码回退。macOS supports passwords, external key paths, Keychain-imported keys, encrypted-key passphrases, and key-first/password fallback.
  • 移动端仅支持密码及导入的 OpenSSH Ed25519/RSA 私钥；不保留外部文件路径，不支持 SSH Agent。Mobile supports passwords and imported OpenSSH Ed25519/RSA keys only; external paths and SSH Agent are unavailable.

主机身份验证Host key verification

  1. 未知主机密钥会暂停连接并显示算法和指纹。An unknown host key pauses the connection and shows its algorithm and fingerprint.
  2. 通过可信渠道核对指纹后，选择仅本次使用或保存信任。Verify through a trusted channel, then choose one-time use or saved trust.
  3. 密钥变化时比较新旧指纹；不要在无法解释变化原因时覆盖信任。When a key changes, compare old and new fingerprints. Do not replace trust if the change is unexplained.
!
没有全局“接受所有主机”No global “accept all hosts”

macOS 与移动端都采用 fail-closed。信任按主机与端口隔离；主机密钥变化不会被静默接受。macOS and mobile both fail closed. Trust is scoped by host and port, and changed keys are never silently accepted.

SSH Config · macOS

macOS 可导入 SSH Config 并展示最终值、来源和不支持项；ProxyJump、代理及转发属于桌面运行能力。移动端导入 OpenSSH Config 只能得到具体主机资料，不会执行 Include、Match、代理脚本或转发行为。macOS imports SSH Config and reports effective values, sources, and unsupported directives. ProxyJump, proxies, and forwarding are desktop runtime capabilities. Mobile may import concrete host data but does not execute Include, Match, proxy scripts, or forwarding behavior.

会话导入与导出Session import and export

可导入：Import: XShell, SecureCRT, MobaXterm, FinalShell, XTerminal, PuTTY, ServerDash JSON, OpenSSH Config.

可导出：Export: ServerDash JSON, OpenSSH Config, XShell, MobaXterm, XTerminal, PuTTY. SecureCRT 与 FinalShell 原生导出仍禁用。Native SecureCRT and FinalShell export remains disabled.

  • 重复主机默认跳过且不覆盖，可逐项选择导入副本。Duplicates are skipped without overwrite by default; individual copies can be imported explicitly.
  • 明文密码导入默认关闭；开启后只写入本设备 Keychain，不破解专有加密密码。Plaintext-password import is off by default; when enabled, values go only to this device's Keychain. Proprietary encrypted passwords are not decrypted.
  • 所有导出都排除密码、私钥正文、口令、主机信任、历史、代理、跳板机和转发规则。Every export omits passwords, private keys, passphrases, host trust, history, proxies, jump hosts, and forwarding rules.
