本页能力仅在 macOS 提供。它们已实现并通过对应的自动化或受控测试，但生产代理、真实 WebDAV、实体串口及长时间稳定性仍取决于部署环境。Features on this page are macOS-only. They are implemented and covered by automation or controlled tests, while production proxies, real WebDAV, physical serial hardware, and long-running stability still depend on the deployment environment.

跳板机、代理与端口转发Jump hosts, proxies, and forwarding

  • ProxyJump 支持多跳路线，每一跳拥有独立身份、主机信任与超时。ProxyJump supports multi-hop routes with independent identity, host trust, and timeout per hop.
  • 支持结构化 SOCKS5 与 HTTP CONNECT 代理。Structured SOCKS5 and HTTP CONNECT proxies are supported.
  • 支持 Local、Remote、Dynamic SOCKS 及 HTTP-to-SOCKS 转发。Supports Local, Remote, Dynamic SOCKS, and HTTP-to-SOCKS forwarding.
  • 默认监听 127.0.0.1；Remote Forward 与远端/广域监听每次启动都需要确认。Listeners default to 127.0.0.1; Remote Forward and remote/wildcard listeners require confirmation on each start.
!
环境验收仍然必要Environment validation remains necessary

生产多跳、认证代理、Remote Forward、硬件密钥、弱网与长时间稳定性尚不能由仓库自动化替代。Repository automation does not replace validation of production multi-hop routes, authenticated proxies, Remote Forward, hardware keys, weak networks, or long-running stability.

本地 Shell、串口与 VNCLocal Shell, serial, and VNC

本地 ShellLocal Shell

可选择登录环境或干净环境；自定义可执行文件必须使用绝对路径。Choose login or clean environments; custom executables require absolute paths.

串口终端Serial terminal

支持 300–921600 波特率、数据位、校验、停止位与流控；设备拔出后需手动重连。Supports 300–921600 baud, data bits, parity, stop bits, and flow control; reconnect manually after unplugging.

VNC

启动 macOS 系统“屏幕共享”。ServerDash 不拥有远程画布、凭据或在线状态。Launches macOS Screen Sharing. ServerDash does not own the remote canvas, credentials, or online state.

验证边界Validation boundary

实体串口与真实 VNC 互操作需要在目标环境人工核验。Physical serial and real VNC interoperability require validation in the target environment.

WebDAV 加密配置同步Encrypted WebDAV configuration sync

同步默认关闭。预览会展示基线变化、删除与冲突；强 ETag 条件保护并发写入，条件失败后必须重新获取预览。Sync is off by default. Previews show baseline changes, deletes, and conflicts. Strong ETag conditions protect concurrent writes; failed conditions require a fresh preview.

  • AES-256-GCM 版本化包包含主机、分组、标签、片段与连接配置。Versioned AES-256-GCM packages include hosts, groups, tags, snippets, and connection configuration.
  • 恢复密钥保存在 Keychain，并支持显式导出/导入。Recovery keys live in Keychain with explicit export/import.
  • 密码、私钥、主机信任、历史、录制、监控、本地目录授权与串口绑定永不进入同步包。Passwords, keys, host trust, history, recordings, monitoring, local directory authorization, and serial bindings never enter sync packages.

真实服务兼容性Real-service compatibility

实际 WebDAV 强 ETag、双设备并发与断网恢复仍需在所选服务上现场验证。Strong ETag behavior, dual-device concurrency, and offline recovery must still be validated against your chosen WebDAV service.

SSH 会话录制SSH session recording

  • 每个 SSH 面板独立录制；切换标签或页面不会停止。Each SSH pane records independently and continues across tab or page changes.
  • 本地 .sdrec 支持 0.25×–8× 回放、跳过空闲和时间轴跳转。Local .sdrec playback supports 0.25×–8× speed, idle skipping, and timeline seeking.
  • 可导出最多五分钟 GIF 片段，设置 1–30 FPS、质量缩放与文字水印。Export GIF clips up to five minutes with 1–30 FPS, quality scaling, and text watermark.
  • 不采集原始按键或隐藏密码输入，但终端回显与输出仍可能包含秘密。Raw keystrokes and hidden password input are not captured, but terminal echo and output may still contain secrets.
!
不是合规审计录像Not a compliance recording

没有可靠自动脱敏、数字签名、防篡改或合规审计保证；它不是像素级屏幕录像。There is no reliable automatic redaction, digital signature, tamper-proofing, or compliance guarantee; it is not pixel-level screen capture.

可选 AI 助手Optional AI assistant

支持 OpenAI、Anthropic/Claude、Gemini、DeepSeek、通义千问、火山引擎/方舟、Ollama 和自定义 OpenAI 兼容 API。每家独立保存地址、模型、参数和 Keychain 凭据，不提供内置账号或额度。Supports OpenAI, Anthropic/Claude, Gemini, DeepSeek, Qwen, Volcengine/Ark, Ollama, and custom OpenAI-compatible APIs. Each stores its own endpoint, model, parameters, and Keychain credential; no built-in account or quota is provided.

  • 终端上下文按 SSH 连接授权，仅在点击发送时采集。Terminal context is authorized per SSH connection and captured only when sending.
  • 单行 Shell 建议可在确认命令与目标后执行；多行脚本只能复制。Single-line shell suggestions may execute after target/command confirmation; multiline scripts are copy-only.
  • 本地保存聊天不代表请求数据不离开设备；保留政策与费用由用户选择的服务决定。Local chat storage does not mean request data stays on-device; retention and cost depend on the selected provider.
!
提供商互操作边界Provider interoperability boundary

适配和受控测试已完成，但项目未用所有真实付费服务做完整互操作验收。模型可用性取决于服务与账号权限。Adapters and controlled tests are complete, but the project has not fully validated every real paid service. Model availability depends on provider and account permissions.
