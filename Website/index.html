安全边界清晰Explicit security boundaries

连接由你发起，信任由你确认You initiate connections. You confirm trust.

没有“接受所有主机”的捷径。未知或变化的主机密钥都会暂停连接，等待明确确认。 There is no “accept all hosts” shortcut. Unknown or changed host keys pause the connection for explicit confirmation.

⌁

无需服务端 AgentNo server-side agent

通过 SSH 按需采集，不安装常驻守护进程或配套服务。Collect on demand over SSH without installing a resident daemon or companion service.

◇

严格主机身份确认Strict host verification

首次指纹确认、密钥变化对比和应用专属 trusted hosts 管理。First-use fingerprint confirmation, changed-key comparison, and app-specific trusted hosts.

⌘

凭据进入 KeychainCredentials in Keychain

密码、私钥正文和口令不会写入 SwiftData，也不会出现在命令行。Passwords, private-key bodies, and passphrases stay out of SwiftData and command lines.

◉

隐私模式与脱敏诊断Privacy mode and redaction

隐藏 IP，并提供可预览、可复制的脱敏 SSH 诊断。Hide IP addresses and preview redacted SSH diagnostics before copying.

原生多端Native across devices
