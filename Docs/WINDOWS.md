# Windows 内部预览与验收记录

ServerDash 已新增 `Desktop/` 跨平台桌面工程，目标是 Windows 11 x64，架构为 Tauri 2 + React/TypeScript + Rust。现有 macOS、iPhone/iPad 应用继续保留；Linux 仍是远端监控目标。

**当前是开发中的内部预览，尚未完整对齐 macOS。Windows CI 已成功生成首个 NSIS 安装包并核对 SHA-256，Windows 11 实机交互验收仍未完成。** 本文区分可检查的实现与后续发布门槛，不将本机共享代码测试视为 Windows 平台验证。

## 已实现的基础

- 独立 Rust workspace、锁定依赖、Tauri 宿主、React 工作台、版本化 SQLite 和 Windows 用户级 DPAPI 凭据适配。
- 机器编辑、搜索、分组/标签字段、列表/网格、多选、身份和密钥记录、可信主机及代码片段入口。
- russh SSH 和 russh-sftp：主机指纹确认、密码/私钥/Agent 认证接口、取消与超时；逐跳认证和信任、SOCKS5/HTTP CONNECT 引擎路径已加入，高级路线编辑器尚未完成。
- xterm.js 多标签与最多 16 个 SSH 面板，应用持有连接、切页保活、搜索、终端尺寸同步和消费确认背压；输入操作绑定会话 ID 与连接代次。
- SFTP 目录浏览、上传下载、传输取消、创建/重命名/删除、权限接口及有冲突检查的远程文本编辑。
- Linux 监控采集与解析、手动/定时刷新、失败记录和本地历史接口；监控数据契约包含 CPU、内存、网络、GPU、Docker 等记录。
- 本地 PTY；Windows 路径使用 ConPTY 和默认 Windows PowerShell，支持指定可执行程序。串口枚举/会话和外部 VNC 客户端启动接口已加入。
- 八类 AI 提供商请求构造、流式解析、模型列表、取消、本地对话、按原 SSH 连接授权上下文，以及绑定原连接的命令确认。
- `.sdrec` v1 写入、LZFSE/SHA-256 编解码、部分文件恢复、只读快照回放和有界录制任务。GIF 导出尚未实现。
- 本地混合协议配置包、WebDAV 预览与条件写、三方冲突处理、墓碑，以及八类会话格式导入。SecureCRT/FinalShell 原生导出继续保持未验证状态，未开放。

以上清单表示代码与入口已经存在；具体 Windows 设备、真实服务器与第三方服务的兼容性仍需验收。

## 数据与迁移边界

Windows 应用使用自身的本地应用数据目录和 SQLite 数据库，不直接打开或迁移 Apple SwiftData 数据库。长期密码、私钥和 AI Key 经 Rust 用户级 DPAPI 加密保存，数据库只保存引用；非 Windows 开发构建的凭据仅在当前进程内存中存在。

本地配置文件是明文配置，可包含主机地址、用户名、备注和命令文本。WebDAV 配置包使用 AES-256-GCM；连接既有同步空间时需要原恢复密钥。WebDAV 仅接受 HTTPS，拒绝转发重定向，检查强 ETag，并在写入用户配置前验证服务确实执行条件写。

迁移和同步排除密码、私钥正文、主机信任、本地目录权限、RDP 目录书签/屏幕 ID、代理凭据及串口设备绑定。SSH 路线每跳的迁移凭据为 Agent 占位，需在本机重新配置；连接前后命令不因导入而获得执行授权。已有本机 RDP 授权不被导入的可移植配置覆盖。配置预览后如本机或远端发生变化，需重新预览。

会话导入允许预览明文密码是否可用，但只有用户明确选择后才保存到本机凭据库；不解密其他客户端的专有密码，不执行导入的 `ProxyCommand`、脚本或转发配置。外部私钥路径仅是提示，不能赋予本机文件访问权限。

## RDP 现状

`Desktop/native/rdp/` 提供 C ABI、Win32 子 HWND、D3D11 交换链与显示冒烟测试；像素保留在原生内存，不经 JavaScript。

`Scripts/build-windows-rdp.ps1` 按仓库校验和构建 FreeRDP 3.31.0、OpenSSL 3.5.8 和显示探针。**这个探针没有连接 Windows 服务器的会话实现，桌面宿主的 RDP 能力仍为 `false`。** 因此不能声称 NLA/TLS 登录、证书确认、键鼠/IME、音频、剪贴板、目录映射、多屏或重连已经可用。探针产物与将来的应用安装包是不同的交付物。
