# 终端工作区

## 架构与边界

`TerminalWorkspace` 管理标签顺序、活跃面板和二叉分屏树。每个叶节点对应独立终端控制器，分隔比例和网格重排不改变连接身份。每标签最多 16 面板，关闭叶节点折叠空分支，关闭标签释放所属会话。

Mac 控制器持有 OpenSSH 进程和 AppKit 终端；移动端由服务器 UUID 改为会话 UUID 索引，控制器持有 UIKit 终端、读取任务和连接代次。关闭/后台中断/重连使旧代次失效，迟到连接立即关闭。移动端输入串行提交，PTY 使用最近布局尺寸，输出直接交给原生终端而非逐块发布 SwiftUI 状态。

SFTP/监控是独立标签，不是可分屏终端。SSH 与 SFTP 由工作区控制器持有，前台切页保留任务，只有当前页面挂载。移动端进入系统后台仍中断连接；返回后由用户明确重连。监控沿用按主机调度。RDP、VNC 和真实 AI 服务尚未接入，不提供假连接入口。标签布局不持久化，应用重启不自动执行命令或重连。

## 搜索、高亮、历史

搜索使用 SwiftTerm 滚屏引擎。高亮将 UTF-16 偏移映射到终端单元格，兼容中文/宽字符/组合字符，不修改输出和复制内容。高亮逐可见行处理，跨视觉换行可能无法整段着色。

最多 32 条高亮规则、每条 256 字符，每行最多 2,048 单元格和 128 个装饰片段，缓存 256 行。正则有时间预算及进度回调中止，复杂表达式可能跳过，不保证任意正则完整着色。

补全来源为本地历史、命令库、片段。命令栏提交前确认，历史重用只填入文字。原生终端通过 OSC 133 B/C 标记识别命令边界，只读取回显命令，不记录原始按键和程序内密码回答。无集成不做按键猜测；用户可确认发送 Bash 4.4+/Zsh 的当前 Shell 集成，不写启动文件或替换 DEBUG trap。

历史仅存本机偏好数据，最多 2,000 条，按主机/命令去重，可关闭或清空。拒绝控制字符、超长命令、前导空格、赋值与常见敏感关键词，但无法保证识别所有秘密。私密命令应关闭记录或加前导空格。历史不进入日志、SwiftData 会话模型或导出包，不同步，不上传 AI。

- iPad Pro 13-inch (M5)、iPhone 17 Pro 模拟器各 84/84 项通过，包含原有本地 SSH/PTY/SFTP、主机信任和迁移安全测试，以及新增工作区测试。
- macOS 全量 204 项中 203 项通过；新增 14 项工作区/终端工具用例全部通过。既有 `ConnectionProcessControllerTests/testCancellationEscalatesAndLeavesNoChildProcess` 仍约 5.1 秒，未满足 1 秒门限，单独复核也失败。后续导航修复已改为事件驱动读取，定向复跑通过，最终全量回归仍待执行。
- 已检查 iPad 四面板和 iPhone 放大面板夹具截图。测试发现并修复了重挂载过程中零尺寸导致终端内容丢失的问题。
- 模拟器 Keychain 测试需要临时签名。使用 `CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=-`；未签名运行产生的 Keychain 身份错误不作为功能通过结果。
- 没有连接实体设备或用户真实服务器。RDP、VNC、在线 AI 建议仍未实现。
