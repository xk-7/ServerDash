# macOS 工作区连接

本轮保留系统 OpenSSH、SwiftTerm 和内嵌 FreeRDP，在 macOS 工作区增加本地 Shell、串口与外部 VNC。数据模型由三端共享；iPhone/iPad 的可创建标签白名单仍只有 SSH、SFTP、监控，桌面专用记录不会开放移动端引擎。

## VNC

- 保存名称、地址、端口、分组、标签和备注，默认端口为 5900；支持 IPv4、域名和 IPv6。
- “打开屏幕共享”调用 `com.apple.ScreenSharing`，凭据由系统客户端处理。ServerDash 不接受含用户名、密码、协议前缀或路径的 VNC 地址，也不把密码写入 URL。
- 只记录系统客户端成功启动时间；没有内嵌 VNC 画布，不宣称远端已经认证或在线，也不代替用户关闭系统屏幕共享窗口。

## RDP

- 继续使用内嵌 FreeRDP、连接前参数校验和原生高级设置。编辑主机的“保存并连接”将本次临时密码交给会话，不要求保存到 Keychain。
- 主机列表的最近连接时间只在引擎确认连接成功后更新，保存在本机活动记录中，不改变旧版 SwiftData 实体或进入同步包。删除主机同时清理该时间；已关闭会话的迟到事件不能恢复它。

## 本地 Shell 与串口

- Shell 路径留空时使用系统账户记录中的登录 Shell，缺失时依次回退到应用继承的 `SHELL` 和 `/bin/zsh`。自定义路径必须是本机可执行文件的绝对路径。工作目录为用户主目录。
- “登录终端环境”继承应用环境并启动登录 Shell；“干净环境”仅保留基本用户、PATH、TERM、LANG，zsh 使用 `-f`、bash 使用 `--noprofile --norc`、fish 使用 `--no-config`。系统级不可跳过的初始化仍遵守 Shell 自身规则。
- 串口由 IOKit 枚举本机 callout 设备，通过 termios 配置并交给 SwiftTerm 渲染。默认 115200 baud、8 数据位、无校验、1 停止位、无流控。可选 300–921600 的列举波特率、5–8 数据位、奇偶校验、1/2 停止位、RTS/CTS 或 XON/XOFF；高波特率仍取决于设备驱动。
- 设备使用独占打开；不存在、占用、权限或驱动参数错误显示在会话内。拔出设备后进入失败状态，需要用户重连。
- 编辑已打开的串口配置不会打断当前会话；点击“重新连接”或“保存并连接”时重新读取已保存的设备和通信参数。已删除的串口记录不能继续重连。
- 串口读写使用同一队列，发送缓存最多 1 MiB。关闭会取消所有读写源，等内核事件注销后恢复 termios、释放独占标记并关闭文件描述符，再允许立即重新打开。
- 本地和串口是独立单窗格标签，不进入 SSH 的监控、SFTP、认证、命令历史、录制或远程 AI 上下文流程。`WorkbenchSessionRegistry` 持有控制器；切换页面保留会话，关闭标签、删除串口记录和退出应用释放会话。重启应用不自动执行 Shell 或重连设备。

## SSH 高级设置

- 新主机默认 Keep-Alive 30 秒、最多失败 3 次、连接超时 15 秒、认证等待 30 秒。没有高级记录的旧主机保留 Keep-Alive 15/3 和已有全局连接超时（默认 8 秒）。编辑旧主机从这些现值初始化。
- 心跳可关闭；范围为间隔 10–300 秒、失败次数 1–10。连接超时接受 5–300 秒以兼容已有全局设置；认证等待为 10–120 秒。
- Direct SSH、路由 SSH 和 SFTP 实际使用相应 `ConnectTimeout`、`ServerAliveInterval`、`ServerAliveCountMax`，关闭心跳传入间隔 0。路由的每一跳保留自己的连接超时，目标使用主机设置。
- 交互终端使用 OpenSSH `LocalCommand` 在认证成功后写入本次会话的临时标记；创建 PTY 本身不会被视为远程连接成功。等待使用单调时钟，总上限为“连接超时 + 认证等待”：例如 15 + 30 秒给整个启动后握手 45 秒，并非精确从 TCP 建连瞬间另计 30 秒。进程失败、主动取消、超时和重连均会清理标记；陈旧会话不能更新新连接状态。
- 本地连接命令默认禁用，须单独启用。连接前命令成功结束后才启动 SSH；连接后命令仅在上述认证标记到达后执行。前命令失败阻止 SSH；后命令失败保留已经建立的 SSH，并显示本地命令错误。
- 前后命令各自运行于独立 `/bin/zsh -c`，最长 30 秒、输出最多 1 MiB。`export`、`cd` 等只影响该次本地命令及其子进程，不修改应用环境，也不传给随后启动的 SSH。它们不会因监控、SFTP、隧道或同步而执行。同步导入保留命令文本但关闭执行开关。
- 会话输出日志默认关闭。启用后原始 SSH 终端输出进入本机 `Application Support/ServerDash/SessionLogs`；新目录 0700、新文件 0600，单文件达到 100 MiB 后写入结束说明并停止记录。日志不包含原始键盘事件，但服务器回显可能含私密数据；日志不参与配置同步。

## 路由与 HTTP 代理隧道

- “连接路线与代理”固定当前已保存主机，可导入 OpenSSH 多级跳板配置并配置 SOCKS5/HTTP CONNECT 上游代理。编辑代理保留已有跳板；同一用户名的密码留空时保留原 Keychain 引用。
- 隧道支持 Local、Remote、Dynamic SOCKS 和 HTTP 代理。HTTP 选项先建立仅监听 `127.0.0.1` 的内部 SSH SOCKS 动态隧道，再启动用户指定的 HTTP 监听端口。SSH 失败或停止会关闭 HTTP 监听及活动客户端；重连会重新建立桥接。
- HTTP 支持绝对 HTTP URL 和 CONNECT。普通请求改写为源站路径并从目标 URL 重建 Host；CONNECT 将目标主机/端口交给 SOCKS。不会绕过 SSH 直接连接目标；HTTP 中的 Proxy-Authorization/Proxy-Connection 不向源站转发。URL 内嵌凭据、畸形/折叠请求头会被拒绝。
- 默认本机监听，广域监听继续使用现有显式确认。HTTP 监听没有额外用户认证层；最多 32 个客户端，请求头最多 32 KiB，阻塞读写最多等待 30 秒。普通 HTTP 强制 `Connection: close`，不支持在一条连接上切换多个源站；CONNECT 流持续至任一端断开或隧道停止。
- 连接数与传输字节未作估算；没有统计数据时显示缺失值。

## 验证

`WorkbenchConnectionTests` 覆盖模型持久化、旧参数兼容、直接/路由 SSH 参数、`ssh -G` 对认证标记参数的实际解析、认证等待成功/超时/取消、本地 Shell 输出、本地命令环境隔离、串口双向 PTY 与饱和写关闭重开，以及 HTTP CONNECT 到本机 SOCKS 的完整字节往返和请求头校验。

独立生产代码探针也已完成 VNC IPv6、真实 PTY 串口双向 IO 与 HTTP→SOCKS 回环验证。没有连接用户的真实 SSH/VNC 主机或实体串口；系统屏幕共享互操作、物理设备拔插/高波特率和真实 SSH 多因素认证仍需要对应设备或服务器验收。
