# ServerDash 1.0.5 发布通知

ServerDash 1.0.5（Build 10）汇集自 1.0.4 以来的 macOS 原生界面打磨、状态保留修复和响应性能优化。继续使用系统字体、语义颜色及浅色／深色模式，不恢复渐变玻璃主题。Swift 5.9、SwiftData V5、同步包、凭据格式、连接协议和移动端功能保持不变；RDP 仍为开发中能力。

## 原生界面与日常操作

- 仪表盘和机器页采用更紧凑的卡片、工具区和自适应表格。窄窗保留“刷新全部”、搜索及首行操作，终端检查器避免重复导航。
- 分组和标签筛选使用稳定目录 ID；父组包含子组，改名保持选择，删除后清除失效筛选，旧名称选择自动迁移。空目录和旧主机默认分组可正确显示与搜索，清除筛选不改变排序。
- 设置使用原生分组表单。终端外观预览在宽窗左右排列，窄窗上下排列且可折叠。本地 Shell 路径先校验草稿，再保存有效配置。
- SFTP 的窄窗操作栏保留路径与搜索，将次要操作收进菜单；权限与压缩弹窗可收缩和滚动。选择、列配置及滚动位置由控制器持有，切页或调整大小后恢复，过滤时清除不可见选择。
- 远程编辑器统一工具栏、自动显示当前长标签并提供搜索匹配位置反馈；修复原生撤销／重做响应链，继续保留文档草稿、编码与保存冲突保护。
- 修复编辑已导入密钥或仅修改备注时可能清除 Keychain 私钥口令的问题；只有明确替换或删除才更新已有秘密。

## 响应性能与可靠性

- 启动一次读取连接路线、高级设置和未结束的监控间隙。历史按批加载，可见主机优先，加载结果按时间合并且不覆盖已经收到的新快照。
- 历史维护从快照发布路径移出，自动和手动维护共享任务；完整时间桶聚合保存成功后才清理原始样本，批次间让出主线程，失败或取消可以安全重试。维护沿用现有 8 秒关闭期限。
- 仪表盘复用目录、搜索与排序投影，并支持用户名搜索；实时监控刷新、窗口缩放和滚动不重建目录索引。
- SFTP 缓存显示与选择索引，滚动锚点不再发布整页更新；修复原生表格行高／尺寸反馈循环，并保留 30pt 行高。
- 编辑器按文档版本和查询建立可取消的后台搜索索引，光标移动使用缓存查找。显示计数仍以 10,000 为上限，但前后导航可以到达更多匹配。终端复用搜索表达式与有界高亮缓存，不改变输出、命令和录制顺序。

同机同工具链的 Release 计算基准中，1,000 主机启动查询子步骤 P95 降低 80.8%，仪表盘元数据筛选降低 33.5%，1／4／16 面板终端高亮降低 61.2%／32.3%／34.8%。这些数字只描述测得的计算路径，不代表完整启动、帧时间或全应用提速。10,000 文件的真实 SFTP 自动化交互未测得提速；历史大型夹具仍有约 168 ms 的单次 SwiftData 提交。完整口径、原始数据、内存观察和限制见[性能验收记录](https://github.com/xk-7/ServerDash/blob/v1.0.5/Docs/MAC_PERFORMANCE_QA.md)。

## 构建与主线

- `main` 固定为 Apple 产品主线；独立 Windows 客户端保留在 Windows 分支。macOS 的远端 Windows RDP 支持不受此规则影响。
- Apple-only 完整 tracked tree 门禁与 PR 检查防止 Windows 客户端源码进入主线；新增隔离 QA 路由和可复现性能基准。
- 正式发布继续从锁定源码冷构建 RDP，校验通用架构与动态链接路径，不提交依赖二进制。

- `ServerDash-1.0.5-iPhone-Simulator.zip`：用于 Xcode iPhone Simulator。
- `ServerDash-1.0.5-iPad-Simulator.zip`：用于 Xcode iPad Simulator。
- `ServerDash-1.0.5-SHA256SUMS.txt`：下载附件的 SHA-256 校验值。

macOS 最低支持 14，使用 ad-hoc 签名且未经 Apple 公证。iPhone/iPad 附件最低支持 iOS/iPadOS 18，均为模拟器应用，不能安装到实体设备；实体设备分发仍需 Apple 签名及 TestFlight/App Store 流程。模拟器安装方法见[安装说明](https://github.com/xk-7/ServerDash/blob/v1.0.5/Docs/SIMULATOR_INSTALL.md)。

## 验证范围

发布前功能源码已完成：

- 严格并发构建与第一方零编译告警检查；macOS 全量执行 557 项测试，1 项可选大型基准跳过、0 失败。
- 独立 Release 基准 31/31 通过，包含大型历史基准；最终原生表格／编辑器回归 33/33 通过。
- 通用 Mac Release、通用 iOS Simulator、无签名 iOS Device 兼容构建及架构／动态链接路径检查；Apple-only 门禁夹具 17/17 通过。
- 真实隔离 QA 窗口中的窄宽布局、浅深色、文件选择和滚动恢复、编辑器搜索及原生撤销，以及合成 1／4／16 终端面板。控制器和 PTY 生命周期由普通 XCTest 回归验证。

正式发布脚本另对 1.0.5（Build 10）执行隔离 RDP 冷构建、应用版本／架构、macOS ad-hoc 签名、DMG 完整性、模拟器 ZIP 和 SHA-256 回读校验；这些附件检查与上述功能源码验证分开记录。

XCUI Runner 在启用 automation mode 时超时，测试方法未执行，运行时验收仍未通过；现有证据不足以确定 TCC 根因。真实窗口检查和普通 XCTest 不能替代 XCUI 通过。实际 VoiceOver 朗读、中文输入法组合操作、实体串口与 iPhone/iPad，以及真实 SSH/VNC/RDP/WebDAV 服务互通未在本轮人工验收，不标记通过。详见[工作台验收记录](https://github.com/xk-7/ServerDash/blob/v1.0.5/Docs/WORKBENCH_UI_QA.md)。
