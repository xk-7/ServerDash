# macOS 文件工作区

文件主页面和终端右侧检查器共用 `MacSFTPController`。检查器使用
`SFTPBrowserView(controller:compact: true)`；主页面使用默认完整表格。
控制器仍由 `AppState.fileControllers` 按主机持有，切换会话或关闭检查器不会
结束另一处正在使用的文件连接。远程编辑器和目录同步由独立的应用级 store 持有。

## 远端能力

- 基础浏览、搜索当前目录、显示隐藏项目、上传、下载、创建目录、重命名、移动、
  递归删除使用系统 OpenSSH SFTP。无需安装服务端代理。
- 远程编辑、本地副本回传、目录清单与内容比较、复制/剪切粘贴、压缩和修改权限还需要远端允许
  SSH 命令，并提供 `python3`。程序会明确检测该命令，不会自动安装运行时。
  不满足条件时显示能力错误，基础 SFTP 仍可使用。
- 高级操作运行固定的 Python 3 标准库程序。路径和参数通过 JSON 传入，
  文件正文始终走 SFTP。路径按字面值处理，拒绝换行、NUL 等控制字符。
- 所有请求沿用主机的凭据、路由和主机密钥信任流程，不跳过主机身份核验。
- 复制和归档保留符号链接条目，不递归跟随链接；编辑和同步写入拒绝符号链接
  目标及父路径。macOS 系统 `/var`、`/tmp`、`/etc` 的标准 `/private` 别名会归一化。

## 文件操作

右键菜单提供复制、剪切、复制路径、粘贴、压缩、编辑、用本地应用打开、下载、
重命名、移动、权限和删除。剪贴板仅在应用内保留，粘贴限定同一主机。
跨主机文件可通过显式下载和上传传递。压缩支持 `tar.gz`、`zip`，已有同名归档
不会被覆盖。文件复制先写入独立暂存路径，完成后再放到目标位置。

“用本地应用打开”会下载一份私有本地副本，记录远端原版本和端点，再交给 macOS 默认应用。
外部应用对副本的修改**不会自动回传远端**。文件工具栏的“本地副本 / 上传修改”入口
和 SFTP 设置页均可查看副本列表；选择“上传修改”后，复用编辑器的版本检查、
暂存上传和原子替换流程回传。内容未变时不会发起上传，远端冲突可选择保留副本、
另存为或明确覆盖。上传失败、移除列表记录或删除主机均不会删除本地文件。
副本回传支持普通文件（包括二进制文件），单份限制 512 MB；拒绝符号链接副本。
下载副本存放在
`~/Library/Application Support/ServerDash/RemoteFiles/LocalCopies/`。

递归删除需要确认，逐层删除目录内容后删除目录自身；符号链接只删除链接。
取消会保留尚未执行的项目，已完成的删除不可撤回。

## 编辑器、草稿与保存冲突

内置编辑器提供多标签、行号、语法着色、搜索、编码选择、重新载入、保存和
另存为。支持 UTF-8、UTF-16 LE/BE、GB18030，并保留支持编码的 BOM。
无法无损转换的内容、二进制文件和特殊文件会拒绝编辑。

默认限制同时打开 5 个文件、总输入大小 10 MB，可在 SFTP 设置调整。
语法着色处理少于 200,000 个字符的文本，较大文本仍可编辑但不着色。保存仍受设置的大小上限约束。
`⌘S` 保存当前标签，`⌘F` 搜索，`⌘W` 关闭当前标签；脏标签关闭前会确认。

编辑内容在短延时后保存为此 Mac 的恢复草稿，重开编辑器可继续操作。
草稿、目录本机绑定和正文暂存位于
`~/Library/Application Support/ServerDash/RemoteFiles/`，目录权限为 `0700`，
写入的状态文件为 `0600`。这些文件不参与 WebDAV 配置同步。它们是普通本机文件，
不是独立加密保险库。

保存流程：

1. 读取时记录 SHA-256、大小、修改时间、inode、权限及所有者信息，并校验下载内容。
2. 在目标同一目录创建唯一、排他的 `.serverdash-edit-*` 暂存文件，正文通过 SFTP
   精确上传到该文件名，不使用本地临时文件名作为远端目标。
3. 提交前重新检查原文件版本，并校验上传内容的 SHA-256。新文件的另存为要求
   目标仍不存在。
4. 保留已有文件的所有者、组和权限，同步暂存内容后以原子替换提交。
   失败或取消时尝试清理本次暂存文件。

远端变化会阻止常规保存。用户可重新载入并放弃本地修改、另存为其他路径，
或明确选择覆盖。覆盖仍校验暂存正文及目标类型。
这是提交前的乐观冲突检查和原子文件替换；无法对不合作的外部写入者提供跨进程
事务锁或严格的原子 compare-and-swap。确认结果丢失时，应刷新检查再决定下一步。

主机地址、端口或用户名改变后，旧草稿不能直接保存到新端点；先导出本地草稿，
再重新打开目标文件。删除主机将取消该主机的编辑操作，但保留本机草稿供导出。

## 目录同步

每个配对由用户选择一个本地目录和一个远端目录。默认是手动双向同步：
先读取双方清单、预览差异，再勾选执行项目。没有历史基线且双方同名文件内容不同时，
以及双方相对基线均发生变化时，默认标记冲突并跳过；用户可逐项选择方向。
执行前再次验证文件内容，预览后变化的文件不会被悄悄覆盖。

有历史基线而一侧缺失的项目显示为“删除冲突”，默认未勾选。用户可选择恢复缺失的一侧，
或明确删除另一侧，然后勾选执行。包含删除的批次还会列出删除方向和路径，要求再次确认。
没有历史基线的单侧文件视为新增文件。

执行删除前先确认另一侧仍然缺失，核对待删文件的内容哈希、大小、修改时间及文件身份。
目录核对身份后只调用非递归的空目录删除；子项目先执行，未选择或新出现的子文件会阻止
目录移除。预览后文件变化会停止删除，已完成的项目保留。这是执行前的乐观检查，
不提供跨两台机器的事务锁。类型不一致、符号链接和特殊文件跳过。
移除目录配对只删除配置，本地及远端文件保留。
单次扫描最多 10,000 个项目、512 MB 普通文件内容。扫描会忽略本功能的
`.serverdash-edit-*` 暂存条目。

自动上传需对每个配对显式开启，并先完成一次手动同步或确认双方内容一致的预览。
其运行边界如下：

- 仅在应用位于前台时，每 10 秒检查本地变化；没有后台常驻进程。
- 启动或重新开启自动上传后的首次检查只建立本机观察快照。应用未运行期间发生的
  更改应手动预览；自动处理观察开始之后新增或内容变化的本地路径。
- 只上传本轮发生变化的本地文件或新目录。不会下载、删除文件，也不会因其他文件
  变化顺带恢复一个远端已删除但本地未变的文件。
- 同名冲突继续跳过并提示手动预览。失败的批次不盲目重试，需手动检查或产生后续更改。
- 关闭自动上传或删除对应主机会取消相关操作；已完成的项目保留。
  一个配对取消不会终止其他配对的轮询。退出应用取消所有任务。
- 地址、端口或用户名变化会停用旧配对，需重新选择并核对目录。

## 持久化与应用接线

V5 的 `DirectorySyncTaskRecord` 是任务目录的唯一来源，保存任务 ID、服务器 ID、
显示名和远端目录。私有 `DirectorySync/machine-bindings.json` 只按任务 ID 保存
本地目录、端点绑定、自动上传授权、内容基线及上次同步时间。两者字段职责不重叠，
本机目录与授权不进入 WebDAV 载荷。

首次 `DirectorySyncStore.configure(container:)` 会将旧 `pairs.json` 的任务元数据迁入
V5，并写入本机绑定。成功后旧文件只保留为迁移备份，不再合并为活跃任务。
删除的数据库任务不会被旧 JSON 复活。只有数据库而没有本机绑定的任务保持未绑定状态，
自动上传关闭，需移除旧配对后重新选择本地目录。加载失败时自动上传保持暂停。

macOS 容器就绪后调用 `DirectorySyncStore.shared.configure(container:)`；
主机初始化时向两个 store 注册 `DesktopFileAccess(server:appState:)`。
删除主机时调用 `unregister(serverID:)`，退出应用时调用 `shutdown()`。
`register` 本身不访问远端。普通文件页关闭只处理其 controller 的原有生命周期，
不取消独立编辑器草稿或移除目录配对。

## 验证范围

`DesktopFileOperationsTests` 使用临时目录和本机 Python/SFTP 子进程验证字面路径、
保存冲突、原子替换、权限、链接边界、复制/移动/归档、编码、同步方向、手动删除版本校验和持久化迁移。
系统 SFTP fixture 使用 `sftp -D /usr/libexec/sftp-server`，无网络和凭据。
`DesktopFileUIFixtureTests` 生成完整文件页、紧凑检查器、编辑器、本地副本列表及目录同步的浅色/深色图。
这些测试不会连接用户保存的主机，不代表对某个真实 SSH 服务端的兼容性验证。
