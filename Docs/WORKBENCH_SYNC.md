# WebDAV 配置同步

同步默认关闭。macOS 的“设置 → 同步”或主机工具栏进入同一页面；iPhone/iPad 不显示该入口。首次使用时填写已存在的 HTTPS WebDAV 目录、用户名及密码，生成恢复密钥，再点击“保存并预览”。另一台 Mac 导入同一恢复密钥后连接相同目录。应用不会自动创建远端目录，也不会跟随重定向发送认证信息。

## 配置与密钥

`ServerDash.configsync` 是版本化 AES-256-GCM 配置包；固定格式头同时作为认证附加数据。密码、私钥正文或引用、主机信任、历史、录制、监控数据、本机文件授权、目录配对绑定与串口设备路径均不在包中。路线中的代理密码和跳板凭据引用被剥离，RDP 本地共享和显示器绑定也保留本机。

包包含 SSH/RDP/VNC/串口配置、分组、标签、代码片段及 SSH 高级设置/路线/隧道规则。文件大小限制 32 MiB、对象数量限制 20,000；字段采用显式白名单。命令文本可以同步，但远端修改的本地命令默认禁用；导入隧道不会启动监听。

恢复密钥为随机 32 字节，保存在本机 Keychain。导出是权限为 `0600` 的 Base64 文本，应与 WebDAV 账户密码分别保存。密钥不会上传；错误密钥、损坏数据或不兼容格式会在应用变更前报错。恢复密钥导入可替换此目录的本机密钥，不能解密使用另一把密钥的历史文件。

## 合并与提交

每个同步空间用独立映射关联远端标识与本地实体。原有 UUID 和凭据引用不会被远端 ID 替代。基线保存上次成功合并后的可移植配置，删除以墓碑保留，以防离线设备再次上传旧记录。

预览显示上传、下载、删除和双方修改；可以展开查看字段差异。双方修改必须选本机或远端；独立主机及片段还可以保留双方。删除分组将主机归入默认分组并提升子分组，不删除主机；删除主机会清理其高级设置、路线和隧道。重新创建同名分组/标签不会被旧墓碑继续删除。

提交先检查本机是否在预览后变化，再将结果暂存在独立、未保存的上下文中。上传使用强 ETag 的 `If-Match`，初次创建使用 `If-None-Match: *`。应用先在独立临时资源上检查服务是否遵守这两类条件写入，随后清理该资源；不能提供条件保证的服务会被拒绝。该过程依照 [WebDAV 的 ETag 与丢失更新语义](https://www.rfc-editor.org/rfc/rfc4918.html#section-8.6)，加密使用 [Apple CryptoKit AES.GCM](https://developer.apple.com/documentation/cryptokit/aes/gcm)。

条件失败、断网、取消或本机并发修改时保留本机配置，需重新预览。不会在收到 `412` 后强制覆盖。PUT 后还会再次检查本机可移植配置，以及本机命令授权、代理凭据引用和 RDP 本地设置是否变化，防止网络等待期间覆盖用户的新设置。远端已经成功但本地保存未完成时，下一次预览会重新获取并合并远端结果。

## 验证与设备验收

主机工具栏另提供本机配置包导入/导出，支持混合协议与当前多选范围，保留原有 SSH 客户端格式向导。文件使用单独的格式标识和映射空间，不复用 WebDAV 同步空间；它是可审查的明文配置文件，包含地址，保存权限为 `0600`。删除记录不应用，包外本机记录不删除。重复导入通过稳定映射关联，不按名称猜测身份。导入先预览差异和冲突，保存后仅刷新未来连接使用的配置，不重启当前会话。

`ConfigurationSyncTests` 使用两个独立内存容器、本机 V4 数据库及 URLProtocol 响应，覆盖幂等映射、凭据排除、父级变更、删除/重建、加密损坏/错误密钥、并发冲突、条件写入不受支持、错误/弱 ETag 和本机授权并发保护。

尚需按部署环境记录真实 WebDAV 互通：服务名称/版本、HTTPS 认证、强 ETag、双设备首次上传、离线修改、删除冲突、错误密钥和中断恢复。测试不连接用户现有 WebDAV 目录。
