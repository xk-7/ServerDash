# RDP 远程桌面（macOS，开发中）

此实现面向 macOS 14+，桌面显示在 ServerDash 的会话标签中。iPhone、iPad
仍仅提供原有功能，不加载 FreeRDP。当前没有 Windows 测试环境，**不能将构建
通过视作 Windows 登录、音频、多屏或文件互传已经验收**。验收状态见
[RDP_QA.md](RDP_QA.md)。本轮不发布正式版。

## 添加与连接

1. 在「机器」中点击添加，选择 **RDP 远程桌面**。
2. 填写名称、地址、端口、用户名及可选域。端口默认 3389，不显示千位分隔符。
3. 填写密码。默认不保存；选择「保存并连接」仅将密码交给本次会话。
   勾选保存才写入独立的本机 Keychain。留空时，连接页会要求补充密码。
4. 机器列表打开详情；会话中的「选择机器」直接打开远程桌面。

普通打开复用最近使用的 RDP 标签，不替已断开的标签自动重连。「新建标签」
创建独立客户端连接，但 Windows 是否复用同一账户的登录桌面由服务端决定。
RDP 标签不显示 SSH 的 Shell、SFTP、录制、AI 和分屏按钮。

## 显示、键盘与性能

默认 1920×1080、32 位色、窗口模式，等比适配并留黑边。宽高为 200–8192，
总画布不超过 32 Mi 像素。可选 16/24/32 位色、动态分辨率以及低带宽预设；
低带宽预设关闭壁纸、拖动窗口内容、菜单动画及主题，保留位图缓存。
底栏显示 FreeRDP 完成协商后的画布尺寸和色深，可能与请求值不同。

选择多个本机显示器后，下一次连接以同一 RDP 连接协商多屏布局；全屏按钮
为每个选中显示器打开窗口。布局或服务端画布不匹配时拒绝错误裁切，需检查
配置或重新连接。拔除显示器会退出这些全屏窗口；不会建立额外登录连接。
动态分辨率依赖服务端 Display Control 能力，未支持时保留原尺寸。

快捷键可选仅全屏远程、始终本地、始终远程；只处理当前 RDP 视图事件，不安装
全局键盘监听。macOS 保留快捷键不能保证拦截。工具栏可发送 Alt+Tab、Windows
键和 Ctrl+Alt+Delete；Control+Option+Shift+Escape 释放键盘捕获。失焦会释放
按键及鼠标按钮。中文输入通过 macOS 输入法提交 Unicode；实际 Windows 输入法
和组合键仍需实机验证。远程像素画面不提供本机 VoiceOver 控件语义。

FreeRDP 解码、连接与文件处理运行在后台，隐藏标签保持连接而停止提取画面。
Metal 使用更新区域上传，GPU 读取期间不修改纹理，不累积无限帧队列。目前 CPU
仍为每个提取的画面复制完整 BGRA 缓冲区；尚未完成 1080p/4K 实测优化，不宣称
硬件视频解码、零性能开销或指定帧率保证。

## 剪贴板、文件和音频

- 文本与文件剪贴板分别授权，默认均关闭。只有前台获得焦点的 RDP 视图交换
  新复制的内容；切换标签不发送既有系统剪贴板，连接之间不共享授权。
- 文件使用文件描述、1 MiB 有界分块和 macOS 文件承诺，不使用目录映射代替。
  远端文件粘贴到 Finder 后才下载；多文件顺序处理，支持取消与超时清理。
  下载使用权限 0600 的临时文件，完成后以不覆盖方式保存，不自动打开文件。
- 不支持剪贴板文件夹；请使用显式目录映射。当前实现未启用 clipDataId 锁定；
  如果远端在粘贴期间更换剪贴板，旧传输会安全中止，需重新复制后粘贴。
- 映射目录由文件选择器授权，默认只读，显示为 SD01、SD02 等；授权失效时
  必须重新选择，不回退共享整个磁盘。访问逐层使用 no-follow 文件描述符，
  拒绝路径穿越、符号链接及硬链接文件读取。读写模式允许新建、重命名和删除，
  **暂时拒绝已有文件覆盖和部分元数据写入**。不把这些限制隐藏成成功操作。
- 音频选本地播放、远程播放或禁用，默认本地播放。打印机、智能卡和麦克风
  不提供开关。音频设备及服务端编解码兼容性仍待 Windows 联调。

## 安全、生命周期与数据

仅支持 NLA/CredSSP、TLS 1.2+，不降级。严格策略要求系统证书验证；确认策略
允许核对签名有效且未过期的自签名证书。指纹按主机+端口存储，与 SSH 信任
隔离。证书变化暂停，拒绝或取消后保持未连接。校验失败不会发送登录凭据。

切换页面、标签或最小化不结束连接。关闭包含文件传输或仍打开的映射文件句柄
的标签会集中确认取消；不同主机不互相清理。显式断开、删除机器、睡眠或退出
释放对应连接。仅成功连接后的临时网络中断，按 1/2/4/8/16 秒最多重试五次；
认证失败、证书错误、注销和手动断开不自动重试。睡眠前已连接且允许重连的
会话唤醒后可尝试恢复；文件传输需重新开始，不保证登录状态或断点恢复。

SwiftData V4 只新增独立 RDP 实体，SSH 字段不变；升级前备份数据库，失败不
自动重建。三端各自保存本地数据库，没有同步。RDP 密码、会话缓存、证书和
目录书签不会进入 SSH 会话导出；密码不写入模型或日志。

## 构建

```sh
bash Scripts/build-rdp-dependencies.sh
xcodegen generate
xcodebuild -project ServerDash.xcodeproj -scheme ServerDash \
  -destination 'generic/platform=macOS' CODE_SIGNING_ALLOWED=NO \
  ONLY_ACTIVE_ARCH=NO ARCHS='arm64 x86_64' build
```

依赖锁定、安全升级依据及许可见 [Vendor/RDP](../Vendor/RDP/README.md)。
