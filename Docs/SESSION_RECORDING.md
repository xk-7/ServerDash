# macOS 会话录制与 GIF 导出

## 开始与停止

1. 连接 SSH，选择要录制的终端面板。
2. 点击现有终端工具栏的“录制”，首次使用时阅读并确认安全提示。
3. 标签显示红色录制图标；工具栏和面板状态栏显示录制时长。
4. 点击“停止”。保存完成后，从侧栏“资源 → 录制”选择文件回放。

每个面板独立录制，支持一个标签内最多 16 个面板分别录制。切换标签、页面、最小化窗口不停止录制；断开、重连、关闭面板、删除服务器、电脑睡眠和退出应用会结束并保存对应录制。新的 SSH 连接不会自动继续录制，也不恢复远端进程。

首版仅支持 macOS 14+ SSH。iPhone/iPad、SFTP、监控页面和整个应用窗口不支持录制。

## 回放与分享

- 选择列表中的录制，或使用“打开录制文件…”访问其他目录中的 `.sdrec` / `.sdrec.partial`。
- 支持暂停/继续、0.25× 至 8× 播放、前后跳转十秒和时间轴拖拽。
- “跳过空闲”默认关闭；开启后把超过两秒的输出间隔压缩为两秒，再应用播放倍速。
- 录制列表支持名称搜索、在 Finder 中显示及移到废纸篓。删除需确认，可以从废纸篓恢复。
- `.partial` 表示录制未正常结束；打开时恢复已验证的完整块，不覆盖或修补原文件。没有完整初始画面的文件不能恢复。

“导出 GIF”可选择最多五分钟的片段，原始录制保留完整内容。参数为 1–30 FPS、1–30 级画质和自定义水印；默认 10 FPS、画质 20、无水印。画质映射为原始像素的 50%–100%，不放大源画面。预览显示输出尺寸；尺寸变化等比适配并留白，水印占用独立底栏。

GIF 保存后可以复制文件、在 Finder 中显示或使用系统分享菜单。是否支持直接粘贴由目标应用决定。长片段、较高帧率和较大终端尺寸会增加导出时间与文件大小；导出在后台串行执行，可取消，临时文件会清理。

导出期间若应用驻留内存比开始时增加超过 512 MiB，或 GIF 临时文件超过 512 MiB，会中止本次导出并提示缩短片段/降低参数。检测在帧边界和编码结束后进行，不是操作系统级硬内存限额；其他任务引起的内存增长也可能触发保护，现有目标文件保持不变。

为避免 ImageIO 多帧目的对象累计保留画面，采用 ImageIO 单帧压缩、独立局部调色板和流式 GIF89a 写出，不缓存完整动画；文件布局依据 [GIF89a 规范](https://www.w3.org/Graphics/GIF/spec-gif89a.txt)，不自行实现 LZW 编码。

## 文件与安全

默认目录：`~/Documents/ServerDash/recordings`。在“设置 → 录制”自定义目录或命名模板，支持 `{date}`、`{time}`、`{name}`、`{id}`。始终保留唯一 ID，非法字符会替换，已有录制不被覆盖。更改目录只影响新录制，不自动移动旧文件；失效授权需要重新选择目录。

只接收 SSH 终端输出及尺寸/显示变化，不监听原始键盘事件，不额外读取 Keychain、SSH 配置或环境变量。开始时包含当前可见屏幕，但不打包此前的隐藏滚动历史；随后跟随实时输出，不录制用户翻阅旧历史的动作。

**输出不是安全保险箱。** 服务器回显、终端初始画面及命令输出仍可能包含密码、令牌、连接地址或业务数据；没有可靠的自动脱敏。录制数据与完整输出仅进入本机录制文件，不进入应用日志、SwiftData 或云同步。请在分享前检查内容。文件默认权限为 `0600`，默认目录为 `0700`；已有/自定义目录权限不被自动更改。

这是用于本地复盘、培训、排障和演示的功能，不是防篡改审计系统，也不保证满足监管要求。

## 实现与兼容范围

`.sdrec` v1 标识为 `com.serverdash.recording`。文件由版本头、独立 LZFSE 压缩块、SHA-256 损坏检测、输出事件、显示增量、关键帧及结束索引组成。校验不是数字签名。每块解压上限 16 MiB，输入还验证尺寸、行索引、时间顺序和结束索引。

输出字节按顺序保存，每个输出事件不超过 64 KiB；终端显示状态最多每秒采集 30 次，仅写入变化行，每五秒及尺寸变化时保存完整关键帧。结束时补采最终画面。该格式不是像素级屏幕录像；极短暂的中间显示可被合并，但输出字节不按帧率丢弃。

SwiftTerm 快照保存真实 Unicode 字符、单元格宽度、颜色、样式和光标，不序列化内部字符索引、链接动作或图片正文。回放和 GIF 使用同一只读 CoreText/CoreGraphics 渲染器，不向终端模拟器重新投送录制的控制序列，不连接 SSH、不执行命令、不修改剪贴板。支持 ANSI 文本、中文、组合字符、Emoji 及正常/备用屏切换；不承诺字体跨系统像素一致。

内嵌图片协议暂不支持，检测到会提示。终端工具栏、选择区域、搜索/自定义关键词高亮叠层和补全弹窗不在录制画面中。

全局待写队列限制为 32 MiB，超过限制或写入失败时停止受影响的录制，保留可恢复文件，并提示用户；SSH 和其他录制不被主动终止。写入、校验、回放解码和 GIF 编码均不把整个录制加载到内存；读取器仅保留关键帧索引和当前屏幕。性能应以实测为准，不宣称零开销。
